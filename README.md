# Персональная интерактивная визитка Захара

Современный, технологичный сайт-визитка с 3D-эффектом параллакса, адаптивным интерфейсом, синтезом звуков (Web Audio API) и динамическим оффлайн QR-генератором.

## 🚀 Возможности
- **3D Карточка**: Реагирует на движение курсора мыши и гироскоп смартфона, отбрасывая реалистичный голографический блик.
- **Интерактивный живой фон**: Анимированные парящие частицы на Canvas, соединяющиеся в созвездия и мягко реагирующие на курсор.
- **Все контакты в один клик**:
  - **Telegram**: прямая ссылка `@pirotekhnik` + кнопка быстрого копирования юзернейма.
  - **Max Messenger**: брендированная кнопка перехода в профиль мессенджера Max + копирование ссылки.
  - **Телефон**: прямой вызов `+7 (996) 341-07-73` + быстрое копирование номера.
- **Сохранение в телефонную книгу (.vcf)**: Нажатие кнопки «Сохранить в контакты» генерирует файл vCard с именем, телефоном и ссылками для мгновенного добавления в контакты смартфона.
- **Встроенный QR-код**: Модальное окно с переключаемыми кодами (визитка, Telegram, Max, телефон), работающими без интернета.
- **Тактильный аудио-отклик**: Легкие футуристичные звуки кликов и успехов (с возможностью отключения звука в шапке).
- **Кнопка «Поделиться»**: Нативное меню шеринга смартфона (Web Share API) с резервным копированием ссылки.

## 📁 Структура проекта
- `index.html` — основная структура и разметка визитки.
- `style.css` — нео-кибер стеклянный дизайн (Glassmorphism), анимации и мобильная адаптивность.
- `app.js` — 3D-параллакс, Canvas-частицы, Web Audio звуки, копирование, генерация vCard.
- `qrcode.min.js` — локальная библиотека генерации QR-кодов (работает 100% оффлайн).
- `avatar.jpg` — ваша фотография в высоком качестве.

## 🌐 Как запустить или опубликовать
1. **Локально**: просто откройте файл `index.html` в любом браузере (двойной клик).
2. **В интернете (бесплатно за 1 минуту)**:
   - **GitHub Pages**: создайте репозиторий, залейте файлы папки и включите Pages в настройках репозитория.
   - **Vercel** или **Netlify**: перетащите папку `zakhar-card` в окно браузера на сайте netlify.com/drop или vercel.com.
